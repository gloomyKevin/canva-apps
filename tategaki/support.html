Common questions

The text looks different from what I expected

The app draws with the fonts installed on your own device, so the same text can look different on another computer. The line under the font selector always names the font actually in use. If it says a preferred font is missing, install that font or choose a different family.

The output looks less sharp than usual

When the text is very long or the font size very large, the app lowers the output resolution so the image stays within the size limit browsers place on drawing surfaces, and shows a note when it does. Reduce the font size or shorten the text to restore full resolution.

A four digit number is lying on its side in vertical text

That is deliberate. One and two digit numbers stay upright; longer runs of digits and Latin letters rotate as a single unit so that they are never split across columns. You can turn this off with the Upright short numbers switch.

Can I edit the text after inserting it?

The app inserts an image, because Canva text elements cannot express vertical columns, line breaking rules or punctuation squeezing. To change the wording, edit the text in the panel and insert again, then delete the old image.
